The OLOS protocol now has a full normative specification in the repository's
`spec/` directory (11 sections plus generated appendices), mapped
section-by-section to the conformance assertion set. `OLOS_SPEC_STATUS` is
bumped to `draft-v1.0.0`, and a new `OLOS_CONFORMANCE_SPEC_REFS` export maps
every conformance assertion ID to the spec section that specifies it.
